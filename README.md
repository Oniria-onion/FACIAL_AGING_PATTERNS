
# FACIAL AGING PATTERNS IN PHOTOGRAPHS OF MEXICAN MEN AND WOMEN FOR THE CREATION OF AGE PROGRESSION PORTRAITS

Age progression portraits support the search for long-term missing persons by incorporating facial changes associated with aging. This study analyzes 14 facial aging markers in 385 Mexican adults aged 20–60 years using standardized photographs and validated photonumeric scales. The results identify sex- and age-related patterns that provide baseline information for creating age progression portraits.

## Repository content
This repository contains the R script used to perform the statistical analyses and the two datasets used in the study.

-O.PatronesdeEnvejecimiento.R: R script containing the statistical analyses.

-datos_crudos_mujeres.csv: Dataset corresponding to female facial aging markers.

-datos_crudos_hombres.csv: Dataset corresponding to male facial aging markers

## Reproducibility
To reproduce the analyses, run Analysis.R with both datasets available in the working directory
